## 主要模块及重点

### access

● 上传：

1.  目前是分 一个上传任务 uploadID ——》 多个Batch ，可追加；

2.  upload finish之后 就不能追加了；

3.  finish 之后通知到 asset服务，创建为 clip、slice、capture

● 下载：

1.  创建 导出任务 —— export id

2.  根据多方获取到 fileids

3.  请求asset 获取所有的 详细信息

4.  组装成 manifest

5.  绑定到 对应的 export

### asset

资产服务--- 维护 用户、上传规则、实际物理文件资产、文件属性、业务类型、文件分组 等信息

其它服务 所有文件信息来源

后续考虑 回流信息的绑定 和 血缘建立

### pipeline

工作流模块—— 依赖底层 argo 工作流引擎 去拉起所需要的 工具容器，执行相应的job

[数据平台使用文档](https://doc.weixin.qq.com/smartpage/a1_AdEAnwYNAEICNyv1yQ0JLQ1K0nn9q?scode=AI4AagdpABEOqn4vfsAdEAnwYNAEI&p=EhF9Qh)——工作流使用指南

[【教程】模板与工作流创建](https://doc.weixin.qq.com/doc/w3_AakAdQbuALgCNZY8ukKUoTQ0P0xTM?scode=AI4AagdpABEVu8DAE1AakAdQbuALg)

● 触发

1.  根据 datatype + targettype 自动触发

2.  页面手动触发

3.  其它服务根据需求 调用接口触发

##### 下载镜像 data-cli-download

|   |   |   |   |
|---|---|---|---|
|环境变量|兼容别名|是否必填|作用|
|WORKFLOW_ID|WORKFLOWID、workflow_id、workflowid|是|工作目录为 /shared/<WORKFLOW_ID>/input。|
|TARGETTYPE|TARGET_TYPE、targettype、target_type|未设置 S3PREFIX 时必填|下载业务对象类型。|
|TARGETID|TARGET_ID、targetid、target_id|未设置 S3PREFIX 时必填|下载业务对象 ID。|
|S3PREFIX|S3_PREFIX、s3prefix、s3_prefix|否|直接按 S3 key 前缀下载；设置后不需要 TARGETTYPE、TARGETID。|
|SERVER|server|否|覆盖本次运行的 bff server。|
|S3_ENDPOINT|S3ENDPOINT、s3_endpoint、s3endpoint|否|覆盖本次运行的 s3.endpoint。|
|S3_BUCKET|S3BUCKET、s3_bucket、s3bucket|是|覆盖本次运行的 s3.bucket。|
|DOWNLOAD_PRESERVE_PATH|download_preserve_path|否|true 或 false，覆盖 download.preserve_path。|
|DOWNLOAD_SKIPNIL|download_skipnil|否|true 或 false，覆盖 download.skipnil。|

##### 工作流产物上传镜像 data-cli-upload

默认执行 dp upload workflow-output "/shared/$WORKFLOW_ID"。

|   |   |   |   |
|---|---|---|---|
|环境变量|兼容别名|是否必填|作用|
|WORKFLOW_ID|无|是|工作流 ID 和工作目录 /shared/<WORKFLOW_ID>。|
|UPLOAD_NODE_IDS|无|是|JSON 节点 ID 数组，选择需要上传和绑定的工作流节点；[] 会成功退出。|
|TARGET_TYPE|无|是|关联目标类型：clip、capture、dataset_version、dataset_version_diff。|
|TARGET_ID|无|是|关联目标的正整数 ID。|
|SERVER|server|否|覆盖本次运行的 server。|
|S3_ENDPOINT|S3ENDPOINT、s3_endpoint、s3endpoint|否|覆盖本次运行的 s3.endpoint。|
|S3_BUCKET|S3BUCKET、s3_bucket、s3bucket|否|覆盖本次运行的 s3.bucket。|
|USER_ID|无|否|覆盖上传用户 ID。|
|RULES_ID|RULESID、rules_id、rulesid|否|覆盖上传规则 ID，必须为正整数。|
|MACHINE_ID|MACHINEID、machine_id、machineid|否|覆盖机器 ID。|

##### 原始数据上传镜像 data-cli-upload-raw

对 UPLOAD_NODE_IDS 中的每个节点，镜像查找 /shared/<WORKFLOW_ID>/<WORKFLOW_ID>-<NODE_ID>-<数字>/output，并分别执行一次 dp upload raw --upload-type client，不执行工作流结果绑定。

|   |   |   |   |
|---|---|---|---|
|环境变量|兼容别名|是否必填|作用|
|WORKFLOW_ID|无|是|工作流 ID 和工作目录 /shared/<WORKFLOW_ID>。|
|UPLOAD_NODE_IDS|无|是|JSON 节点 ID 数组，用于匹配需要上传的 pod output 目录；[] 会成功退出。|
|ASSET_TYPE|asset_type|是|原始资产类型：clip 或 capture。|
|SERVER|server|否|覆盖本次运行的 server。|
|S3_ENDPOINT|S3ENDPOINT、s3_endpoint、s3endpoint|否|覆盖本次运行的 s3.endpoint。|
|S3_BUCKET|S3BUCKET、s3_bucket、s3bucket|否|覆盖本次运行的 s3.bucket。|
|USER_ID|USERID、user_id、userid|否|覆盖上传用户 ID，必须为正整数。|
|RULES_ID|RULESID、rules_id、rulesid|否|覆盖上传规则 ID，必须为正整数。|
|MACHINE_ID|MACHINEID、machine_id、machineid|否|覆盖机器 ID。|
|UPLOAD_BATCH_SIZE|upload_batch_size|否|单个 SDK 上传批次的最大文件数；必须为非负整数，0 使用 SDK 默认值。|
